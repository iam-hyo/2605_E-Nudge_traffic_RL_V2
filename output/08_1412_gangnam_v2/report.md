## 2. 핵심 발견

### 2.1 OD-3 도달 완전 해결 (0% → 93~100%)

v1에서 RL 3종 모두 OD-3 0%(degree-1 stub U턴 무한루프)였다. v2의 **U턴 300 + 재방문 50 페널티 + 동적 OD 부스트** 조합으로:

| OD-3 | v1 | v2 (off/peak) |
|---|---|---|
| rl_base | 0% | 97% / 93% |
| rl_signal | 0% | 100% / 100% |
| rl_signal_attention | 0% | 100% / 100% |

학습 로그상 동적 부스트가 OD-3(도달률 최저)를 자동으로 최다 샘플링(ep100에서 od3 n44 > od1 n33 > od2 n23)했고, OD-3 도달률이 0%→96~98%로 수렴. **토폴로지 traversability(v1 해결) + 학습 신호 OD별 균등성(v2 해결)** 이 별개 문제임을 실증.

### 2.2 신논현 OD-1 — 신호 회피 효과 강하게 발현

| OD-1 신논현 peak | 연료(mL) | vs 최단 |
|---|---|---|
| ① shortest | 1715 | — |
| **② fuel_TDD** | **1298** | **−24.3%** |
| ④ rl_signal | 1393 | **−18.8%** |
| ③ rl_base | 1435 | −16.3% |
| ⑤ rl_signal_attention | 1502 | −12.4% |

거리최단은 강남대로 정체를 직진 통과(대기 1174s!) → fuel_TDD는 우회로 대기 285s로 **−24.3%**. v1 한남 OD-1(−6.6%)을 신논현으로 교체한 것이 정확히 적중. 12x12(−19.6%)에 필적하는 강남 실데이터 결과.

### 2.3 RL의 도달성-연료최적성 트레이드오프

OD-3에서 RL은 **도달은 하나 연료는 최단보다 높음**(rl_signal peak 1457 vs shortest 1368, **+6.5%**). U턴/재방문 페널티가 보상을 지배해 "루프 없이 일단 도달"로 학습된 결과 — 도달성을 얻는 대신 OD-3 연료최적성을 일부 양보. 종합 절감폭이 12x12(−12~17%)보다 작은(−0.4~−3.8%) 주된 이유.

### 2.4 ⭐ attention 역전 — 12x12 최고 → 강남 최악

| 순위 | 12x12 (`output/21_1757`) | 강남구 v2 |
|---|---|---|
| RL 1위 | ⑤ attention **−16.6%** | ③ base **−3.8%** |
| RL 2위 | ④ signal −13.3% | ④ signal −1.5% |
| RL 3위 | ③ base −12.1% | ⑤ **attention +0.4%** |

12x12에서 attention < signal < base(낮을수록 우수)의 깔끔한 순서가 강남에서 **완전 역전**. attention은 OD-1 peak step 82.4(signal 59.1)로 가장 비효율 경로, std 최대(OD-2 ±280). **도달하나 가장 나쁜 경로로 도달**.

**원인 4가지:**

1. **과제 성격 변화 (결정적)** — 12x12는 신호 노드 **67%**(97/144) + 최단경로가 "대각 신호지옥"인 **신호 기반 함정** → attention의 특기(신호 phase 미세 식별)가 직접 보상받는 홈그라운드. 강남은 신호 노드 **11.6%**(231/1995) + 문제 본질이 **토폴로지 주행성/stub 회피** → attend할 신호가 희소하고 보상은 "루프 회피·도달"이 지배 → attention 특기 무력화.

2. **12x12에서 예고된 리스크 현실화** — 12x12 §8: *"base·signal 4000ep 수렴, attention 60~80% 불안정 → 6000ep 필요(1.5×). 1995노드 전이 시 학습 비용·안정성 핵심 리스크."* v2는 세 모델 모두 15000ep 동일 배정 → attention만 상대적 under-fit (12x12에선 attention에 1.5× 더 줬으나 여기선 미적용).

3. **페널티 지배 보상 + 3-OD 분산** — uturn 300 + revisit 50가 보상 지배 → 학습 목표가 "연료 최소"에서 "루프 없이 도달"로 이동. 파라미터 많고 수렴 느린 attention이 분산된 3-OD·하드 OD-3 환경에서 단순한 base/signal 대비 불리.

4. **강남 OD는 12x12만큼 극단적 신호함정 아님** — fuel_TDD(오라클)도 −11.1%(12x12 −19.6%)로 절감폭 자체가 작음. attention의 미세 최적화 여지가 작음.

> **한 줄 요약**: 12x12는 attention의 시험문제(신호 식별)였고, 강남은 robustness 시험문제(하드 그래프 항행)였다. 과제가 바뀌니 순위가 뒤집혔다.

## 3. 다음 방향성

### 3.1 모델 개선

| 방향 | 내용 |
|---|---|
| **보상 anneal (최우선)** | uturn/revisit 페널티를 학습 워밍업용 보조로 쓰고 도달 안정화 후 **점진 감쇠** → 후반엔 순수 fuel 보상으로 연료최적성 회복 (현재 페널티가 끝까지 지배해 종합 −0.4%까지 붕괴). |
| **attention 공정 재학습** | 12x12 교훈대로 attention에 1.5~2× epoch 또는 lr·warmup 별도 튜닝. 동일 예산은 불공정. |
| **sparse-attention 구조** | 신호 11.6%뿐인 강남 → attention을 **신호 노드에만** 거는 sparse-attention, 또는 무신호 구간 base 폴백 hybrid. |
| **fuel-potential shaping** | shaping을 거리뿐 아니라 예상 연료 기반 potential로 → OD-3 도달+저연료 동시 유도. |
| **커리큘럼 정식화** | 동적 OD 부스트 효과 입증 → 단거리→장거리·easy→hard 단계 커리큘럼 확장. |

### 3.2 실제 서빙 가능성

| 항목 | 현황·과제 |
|---|---|
| **추론 비용** | RL은 1-step forward(ms) → 실시간 라우팅 가능. fuel_TDD는 매 노드 전체 Dijkstra(1995노드 느림) → **RL이 서빙 속도 우위**. |
| **모델-프리 강점** | RL은 신호 사이클·속도 기댓값 미지에도 동작 → 실데이터 미비 지역에 강함. fuel_TDD는 SPAT 전수 필요. |
| **선결 데이터** | 일방통행(ONEWAY)·실측 회전제한·실 SPAT 미반영 → 현 해는 시뮬 유효, 실배포엔 3종 데이터 정합 필수. |
| **OD 일반화** | 현재 3-OD 고정 학습. 서빙엔 임의 OD 일반화 검증 필요 (엣지-상대 행동공간이 토폴로지 불변이라 유리한 출발점). |
| **통합 시나리오** | TMAP/Kakao 대비 저연료 경로 절감량 A/B → 내비 "에코 모드" 플러그인. |

### 3.3 기대효과와 한계점

**기대효과**
- 출근 첨두 실 동선(신논현→수서)에서 연료 **−24%(오라클)·−19%(RL signal)** 정량 이득.
- 도달성 0%→97~100%로 **실 도로망 RL 학습 성립** 증명(이전 negative result 극복).
- 모델-프리 RL이 환경모델 오라클의 상당부분 추격 → 실데이터 부족 환경 배포 잠재력.

**한계점**
- 신호 회피 이득은 **첨두·특정 OD 의존**(off-peak·OD-2/3은 약함). 상시 이득 아님.
- **페널티-연료최적성 트레이드오프** — RL 도달 robust하나 연료최적성 일부 상실(특히 OD-3). 보상 anneal로 해결 과제.
- **attention 규모 확장성** — 신호 sparse·대규모에서 단순 모델 대비 열위. 구조 재설계 필요.
- **실도로 데이터 정합**(일방통행·회전제한·SPAT) 미완 → 현 해는 시뮬 유효성에 한정.

## 5. 한계 및 문제점 (방법론)

1. **페널티 지배로 연료최적성 저하** — uturn/revisit 페널티가 보상을 지배해 RL 종합 절감폭이 v1·12x12 대비 축소. 보상 anneal 필요(§3.1).
2. **attention under-fit** — 동일 epoch 배정으로 attention 불리(§2.4). 공정 비교엔 attention 별도 학습 예산 필요.
3. **일방통행/회전제한/SPAT 실데이터 미반영** — 현 해는 시뮬 내 유효.
4. **신호 인스턴스 고정** — 강남 SPAT 한 인스턴스. 신호 일반화 별도 과제.
5. **OD 고정 학습** — 임의 OD 일반화 미검증(서빙 선결).
