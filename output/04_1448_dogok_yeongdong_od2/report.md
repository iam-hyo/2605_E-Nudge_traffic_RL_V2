## 1. 실험 의도

OD-1 신논현 재실험(노션 "0530 신논현 OD-1")은 **거리최단 ≠ 연료최단** 가설을 강남대로
정체 corridor 에서 발표 임팩트 수준(−20.8%)으로 입증했다. 본 OD-2 재실험은 사용자 요청에 따라:

1. **좌하단(SW) → 우상단(NE) 경향성을 유지**하는 OD 에서 같은 가설을 재검증
   (기존 OD-2 양재→영동의 방향성 계승),
2. 환경을 **신호가 대폭 강화된 `gangnam_topology_add.json`** 으로 교체 — 신호 노드가
   231→614개(2.7배), 좌회전허용 138→259개. 신호가 조밀해질수록 거리최단 corridor 의
   누적 대기·연료가 폭증하므로 RL 의 신호회피 학습 우위가 더 선명해질 것이라는 기대,
3. OD-3 는 제외(사용자 요청), OD-1 은 **일반화 참고용**으로만 유지.

> **핵심 질문**: 신호가 2.7배 조밀한 환경에서 (a) 거리최단이 얼마나 더 불리해지는가,
> (b) 모델-프리 RL 이 신호회피를 학습해 거리최단을 이기는가, (c) 시간의존 Dijkstra
> 오라클(fuel TDD)에 얼마나 근접하는가, (d) RL 3종 중 신호인식 모델이 우월한가.

## 5. 경로 분석 — 거리최단 vs 연료최단 corridor 분기

deterministic(노이즈 제거) peak 경로:

| 경로 | 랜드마크 시퀀스 | 스텝 | 신호 | 대기 | 연료 |
|---|---|---|---|---|---|
| **거리최단 (short)** | 도곡역→역삼역→**선릉역→한티역→삼성역**→청담역→영동대교 | 54 | **35** | 1332s | 1365 |
| **연료최단 (fuel TDD)** | 도곡역→역삼역→**언주역→학동역→선정릉**→청담역→영동대교 | 62 | 25 | 516s | 1019 |

두 경로는 **역삼역 부근(공통 12노드)** 까지 동일하다가 분기: 거리최단은 동쪽
**테헤란로(선릉~삼성)** 신호밀집 corridor 직진, 연료최단은 북서쪽 **언주로(언주~학동~선정릉)**
로 +8스텝 우회. 우회로는 신호 10개 적고 대기 −816초 → 거리 +630m 손해를 상쇄하고
연료 −25%(noise0). 신호 2.7배 환경에서 "테헤란로 = 신호 hell, 언주로 = 상대적 green
corridor" 구조가 가설을 그대로 시연.

**RL 모델이 학습한 greedy 경로 (peak)**:

| 모델 | 경로 | 스텝 | 신호 | 연료 | 도달 |
|---|---|---|---|---|---|
| rl_base | 도곡→역삼→선릉→삼성→청담→영동 | 60 | **24** | 1136 | ✅ |
| rl_signal | 도곡→역삼→선릉→**선정릉**→청담→영동 | 73 | 36 | 1498 | ✅ |
| rl_signal_attention | 도곡→역삼→선릉→삼성→청담→영동 | 60 | **24** | 1136 | ✅ |

**base 와 attention 은 동일한 24-신호 하이브리드 경로**(거리최단의 테헤란로 골격을
유지하되 신호 적은 변형, 연료 1136 — short 1365 와 oracle 1019 사이)를 학습. rl_signal 은
오히려 **더 나쁜 36-신호 우회(1498)** 를 greedy 선택 — 신호인식이 손해로 작용.

## 6. 핵심 발견

### 6.1 가설 입증 — 신호강화 환경에서 거리최단의 대기 폭증, RL 의 신호회피

신호 2.7배 토폴로지에서 거리최단의 peak 대기는 **1312초**(OD-1 clean 환경의 신논현
1182초보다도 큼). RL 3종 모두 거리최단을 −8~−11% 이기며 대기를 841~874초로 단축. **모델-프리
RL 이 신호밀집 corridor 를 회피하는 정책을 학습**함을 재확인.

### 6.2 ⚠️ 부정적/미묘한 결과 — RL 이 오라클에 미달, 신호인식이 우위 아님

OD-1 신논현(clean)에서는 rl_signal 이 −20.8% 로 오라클(−23.6%)에 사실상 동급이었으나,
**본 OD-2 에서는 RL(−8~−11%)이 오라클(−18.9%)에 ~8~10pp 미달**하고, **신호 미인식 rl_base 가
신호인식 모델과 같거나 더 우월**하다. 원인 분석:

1. **모델-프리 한계 ×신호 밀도**: 오라클(fuel TDD)은 모든 신호의 위상·사이클을 알고
   *수 신호 앞을 계획*한다. RL 은 현재 노드 SPAT 위상만 관측해 *근시안적*. 신호가 2.7배
   조밀해지면 "여러 신호 앞 타이밍 정렬"의 가치가 커지는데 이는 모델-프리가 학습하기
   가장 어려운 부분 → 오라클 격차가 OD-1 보다 오히려 벌어짐.
2. **rl_signal 의 과적합 추정**: greedy 경로에서 rl_signal 만 36-신호 열등 경로 선택.
   229-d flat 신호 MLP 가 71% 가중된 단일 corridor 의 noisy SPAT 특징에 과적합해 brittle
   정책을 학습한 것으로 추정. 반면 신호 입력이 마스킹된 rl_base 는 **기하학적 우회**만
   단순 학습 → 더 robust. attention 은 base 와 동일 경로로 수렴.
3. **짧은 corridor**: OD-2 는 5.8km/54스텝으로 OD-1(9.2km/80스텝)보다 짧아 신호회피의
   절대 이득이 작고, 신호 상태표현의 한계비용이 이득을 압도.
4. **평가 노이즈**: 실험 평가는 ε=0.05(5% 무작위)+속도 노이즈로 RL std 가 ±100~162 로 큼
   (oracle ±68). greedy(ε=0)에선 base/attention 1136mL(−16.8%)로 훨씬 좋아 — 30회 평균의
   −8~−11% 는 탐험·속도 노이즈가 평균을 끌어내린 결과(§7 추가실험 C 로 검증 제안).

> **요지**: 모델 간 평균 차이(−8.1 vs −10.6%)는 표준편차 내라 통계적으로 유의하지 않다.
> 분명한 것은 (a) RL 전부 거리최단을 이기지만, (b) 본 환경·OD 에서 **신호 상태 입력이
> 신뢰할 만한 이득을 주지 못했고**, (c) **모델-프리 RL 이 모델-기반 오라클에 미달**한다는 점.

### 6.3 일반화 trade-off (심각) — primary_boost 71% 의 대가

OD-1 참고 경로에서 RL 도달률이 base/signal 0%, attention 13~20% 로 붕괴. OD-1 재실험의
OD-2 약화(+1~6% 연료 손해)보다 **훨씬 심각한 완전 미도달**. attention 이 가장 덜 붕괴 —
토큰 단위 표현의 일반화 이점 재확인. 단일 OD 특화 학습 vs 다중 OD 일반화의 명시적 trade-off.

### 6.4 attention: 학습 도달률 최고이나 eval 연료는 중위

attention 은 학습 최종 도달률 90.5%(최고)·OD-1 부분 생존 유일 모델이나, OD-2 eval 연료는
중위(−8.9% peak, −5.6% off). 즉 **"안정적 도달"과 "연료 최소"가 분리** — attention 의 강점은
연료 최적화보다 robust 한 경로 완주에 있음.

## 7. 결론

1. **신호 2.7배 강화 환경에서도 거리최단 ≠ 연료최단 가설은 성립**: 도곡→영동 peak 에서
   거리최단은 테헤란로 직진으로 대기 1312초, 연료최단 오라클은 언주로 우회로 −18.9%.
   **RL 3종 모두 거리최단을 −8~−11% 이기고 대기를 단축** — 모델-프리 신호회피 학습 재확인.
2. **단, RL 은 오라클에 미달하고 신호인식이 우위가 아님(부정적 결과)**: OD-1 신논현에서
   rl_signal 이 오라클 동급이던 것과 대조적. 신호 밀도↑·corridor 짧음·모델-프리 근시안이
   복합 작용. rl_base ≈ attention > rl_signal(과적합 추정), 단 차이는 노이즈 내.
3. **OD 가중 71% 의 일반화 붕괴**: OD-1 참고경로 RL 도달률 0~20%. 단일 OD 발표 성능과 다중
   OD 일반화는 강한 trade-off. attention 이 가장 덜 붕괴.

## 8. 한계 및 개선·검증 추가 실험 제안

### 한계
1. **모델 간 차이가 노이즈 내** — ε=0.05+속도노이즈로 std ±100~162. 단정적 모델 우열 판단 불가.
2. **OD-1 일반화 완전 붕괴** — primary_boost 71% 의 직접 비용.
3. **오라클 격차 미해소** — 모델-프리 RL 이 신호 타이밍 계획을 학습하지 못함.
4. **단일 OD-2 인스턴스** — 하나의 OD 결과라 일반화 주장 제한.

### 추가 실험 제안 (검증 → 개선 순)

| # | 실험 | 목적 | 가설 |
|---|---|---|---|
| **A** | **greedy(ε=0) 평가** 재실험 | §6.2-4 검증 | greedy 면 base/attn −16.8% 로 oracle 근접 — 평균 저하가 탐험 탓인지 확인 |
| **B** | **균등 OD 가중(primary_boost=0)** ablation | 과적합·일반화 검증 | rl_signal 과적합 완화 + OD-1 도달률 회복? OD-2 절감폭과 trade-off 측정 |
| **C** | **신호 타이밍 특징 추가** (time-to-green / 다음 위상까지 잔여초) | 오라클 격차 개선 | 모델-프리에 *신호 선행정보* 주입 → rl_signal 이 오라클에 근접 |
| **D** | **오라클 모방학습 warm-start** (fuel TDD 경로 BC → RL 파인튜닝) | 오라클 격차 개선 | 모델-기반 정책으로 초기화 후 RL 미세조정 → 오라클 상회 시도 |
| **E** | **명시적 대기 페널티 항** 추가 (−β·wait) | 신호회피 신호 강화 | 연료에 묻힌 idle 비용을 분리 보상해 신호회피 정책 선명화 |
| **F** | **다중 OD-2 인스턴스**(338156→341264 등 상위 후보 3개) 평균 | 일반화 검증 | 단일 OD 우연이 아닌 corridor 보편 현상인지 |

**우선순위**: A(즉시·저비용 검증) → C/E(개선) → B/F(일반화). 특히 **A 는 §6.2 의 "RL 이
약한가 vs 탐험 노이즈인가"를 가르는 결정적 검증**이라 최우선 권장.
